# Agent reference

Details agents need that `AGENTS.md` does not cover.

## MCP

Laravel Boost runs as a stdio MCP server: `php artisan boost:mcp`, started from the repository root. It gives version-aware docs (`search-docs`) and app tools. Boost registers its commands only when `APP_ENV=local` or `APP_DEBUG=true`.

- Codex: `.codex/config.toml` registers it.
- Claude Code: copy the `laravel-boost` entry from `.mcp.example.json` into `.mcp.json`. Orbit workspaces already have an `.mcp.json` with Orbit's server; add the entry, do not replace the file.

`boost.json` turns off Boost's generated guidelines, skills and MCP config writes. The skills in `.agents/skills` are curated by hand; `.claude/skills` links to them.

## Frontend

`vite.config.ts` uses `defineLaunchConfig()` from `@nckrtl/launch-ui/vite`. It bundles laravel-vite-plugin, @inertiajs/vite (SSR), @vitejs/plugin-react, @tailwindcss/vite, Wayfinder and the `typescript:transform` runner. Options include `i18n`, `react`, `wayfinder`, `inertia`, `plugins` and `lint`. `vp check` runs type-aware lint with TypeScript type checks.

i18n is off. With `i18n: true`, Launch loads `lang/*.json` and injects `initI18n()`. Use `__()`, `useLocale()` and `setLocale()` from `@nckrtl/launch-ui/i18n`. Placeholders: `:name`, `:Name`, `:NAME`.

Name every web route in `routes/web.php` with dots (`projects.show`). Add components with `bunx shadcn add <name>` or `bunx shadcn add @launch/<name>` (style `base-nova`, Lucide icons).

## File map

- `resources/js/pages/`: Inertia pages. `resources/js/actions/` and `routes/`: generated by Wayfinder; do not edit.
- `resources/js/components/ui/`: shadcn primitives. `resources/css/theme.css`: design tokens.
- `app/Support/Csp/`: Spatie CSP presets (Basic, Development).
- `resources/markdown/`: served by `AgentDocsController`. Edit the Markdown; no rebuild is needed.
